Why are there two exponential terms?

EXP #1 · Rescale history

correction = exp(old_max − new_max)

Rescales the previous denominator and output accumulator when the maximum changes. On the first tile, correction is 0 (no history).

EXP #2 · Score exponentials

weights = exp(scores − new_max)

Converts this tile's logits to unnormalized positive weights.

Softmax = numerator / denominator

Numeratoracc = Σ exp(score−m) · V
Denominatorl = Σ exp(score−m)
Final output: O = acc / l

For simplicity, this example handles one Q tile and three KV tiles. A complete attention launch processes all query tiles (often in parallel). Shapes above assume value head dimension equals key head dimension.

What to look for

  1. Step through tile 1: the correction factor is zero because there is no history yet.
  2. In tiles 2 and 3, watch how the row maximum changes and earlier values get rescaled.
  3. Observe that weights are not yet normalized before PV.
  4. At the end, a single division produces the final attention output.
This example uses non-causal, unmasked attention. Causal/padding masks must be applied to scores before row_max, and fully masked query rows need safe handling. The stages are algorithmic, not a cycle-accurate GPU schedule. Production kernels may use exp2, warp reductions, specialized MMA/bDPAS, asynchronous memory movement, and mixed precision.
